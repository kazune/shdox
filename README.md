# shdox

shdox は、Bash 関数の `##` ドキュメントコメントを検証・整形し、Markdown に変換する CLI です。

## 背景

関数の目的や使い方を自然に書けるように、概要やタグの説明文は自由記述にしています。
コメントの構造やタグの構文・出現回数・許容値を明確に定めることで、CI での形式検証と Markdown 生成に同じコメントを使えます。
Bash の位置引数には静的な型宣言がないため、`@param` は引数の位置と説明文で構成し、必要な値の形式や条件は説明文に記述できます。

## ビルド

Go 1.26.0 以上が必要です。
リポジトリのルートでビルドします。

```sh
go build -o shdox .
```

## コメントの書き方

ドキュメントコメントは Bash 関数の宣言直前に置きます。
概要は1行で、詳細説明とタグは省略できます。
セクションや詳細説明の段落は、`##` だけの行1つで区切ります。
独立した `##` コメント行はすべて検証対象です。

以下を `example.sh` として保存します。

```bash
## Bash ファイルに整形差分があるか確認する。
##
## @param $1 検査する Bash ファイルのパス
## @return 0 整形差分なし
## @return 1 整形差分あり
## @return 2 shdox の処理エラー
## @exit 1 指定したパスが通常ファイルではない
shdox_fmt_check() {
	[ -f "$1" ] || exit 1
	shdox fmt -d "$1" >/dev/null
}
```

## 使い方

| コマンド | 動作 |
| --- | --- |
| `./shdox check example.sh` | コメントの構文・配置・タグの値を検証する。 |
| `./shdox fmt example.sh` | 整形済みの Bash ソースを標準出力に書く。 |
| `./shdox fmt -d example.sh` | 整形前後の差分を標準出力に書く。 |
| `./shdox fmt -w example.sh` | 変更がある場合はファイルを上書きする。 |
| `./shdox generate example.sh` | ドキュメント付きの関数を1つの Markdown 文書として標準出力に書く。 |

ファイルは複数指定でき、指定順に処理されます。
引数 `-` を1回指定すると標準入力を使えます。
`fmt -w` ではファイルを指定してください。

```sh
./shdox check - < example.sh
./shdox generate example.sh > functions.md
```

## 終了コード

| コード | 意味 |
| --- | --- |
| `0` | 処理成功を表し、`fmt -d` の場合は差分なしを意味する。 |
| `1` | `fmt -d` が成功し、差分あり。 |
| `2` | 引数、入力、入出力などのエラー。 |

タグの一覧や検証・整形の規則は [shdox 仕様](docs/shdox.md) を参照してください。
