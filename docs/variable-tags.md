# 変数タグ

タグ全体の構文と検証規則は [shdox 仕様](shdox.md) を参照してください。

| タグ | 記述する内容 |
| --- | --- |
| `@env <name> <description>` | 実行環境から受け取る入力として参照する環境変数 |
| `@global <name> <description>` | 呼び出し元と同じシェル内で共有する入力として参照する変数 |
| `@sideeffect <description>` | 呼び出し元に残る変数の設定・更新・解除などの副作用 |

`@env` と `@global` には変数名と説明文を書きます。
変数名は全シェル方言で共通とし、ASCII の英字またはアンダースコアで始まり、続けて ASCII の英数字またはアンダースコアを任意の個数書けます。
それぞれのタグは、変数名が異なれば出現回数に上限はありません。
変数名や説明文の欠落、不正な変数名、同種タグでの同名変数の重複は検証エラーとし、既存タグと同じ診断形式で報告します。
両方のタグをファイル用と関数用のブロックで使用できます。
ファイル用のブロックにはスクリプト全体が参照する変数を、関数用のブロックにはその関数が参照する変数を書きます。
タグは呼び出し側が値を渡す経路に従って選び、`export` の有無だけで分類は変わりません。
同じブロック内で同じ変数名を `@env` と `@global` に1回ずつ書くことができ、その場合はそれぞれの説明文に対応する使い方を書きます。
必須かどうか、既定値、未設定や空文字の扱いは、必要に応じて説明文に書きます。
同じ変数を入力として参照し、呼び出し元に残る変更も行う場合は、入力を `@env` または `@global` に、変更を `@sideeffect` に書きます。
書き込みだけを行う場合は `@sideeffect` に書きます。

```sh
## 作業ディレクトリを準備する。
##
## @env TMPDIR 一時ディレクトリの親。未設定または空なら /tmp を使う。
## @global work_dir 現在の作業ディレクトリ。設定済みなら再利用する。
## @sideeffect work_dir が未設定または空なら、作成したディレクトリのパスを設定する。
```

## 整形と生成

`fmt` と `generate` は、`@param` の直後に `@env`、`@global` の順で配置します。
`fmt` と `generate` は、`@env` と `@global` のそれぞれで、項目を変数名の ASCII 辞書順に並べます。
例えば、`Z`、`_path`、`a`、`a10`、`a2` の順になります。
`generate` は、`@env` を `Env`、`@global` を `Global` の見出しで出力し、該当するタグがないセクションは省略します。
各項目は `- `、変数名のインラインコード、`: `、説明文の順で出力します。

## 互換性

`@env` と `@global` を含まない入力では、`check` の結果と診断、`fmt` と `generate` の出力を維持します。

## 受け入れテスト項目

| 区分 | 確認する動作 |
| --- | --- |
| 正常系 | ファイル用・関数用の両方で、異なる変数名を持つ同種タグの複数記述と、同名の `@env`・`@global` の併記を受理する。 |
| 境界値 | `_` や `A0` を変数名として受理する。 |
| 不正入力 | `1PATH`、`$PATH`、非 ASCII の変数名、変数名や説明文の欠落、同種タグ内の同名重複を既存タグと同じ診断形式で報告する。 |
| 整形 | タグ種別の順序、同種タグ内の ASCII 辞書順、再整形時の出力の一致を確認する。 |
| 生成 | タグ種別の順序、同種タグ内の ASCII 辞書順、見出しと項目の書式、空セクションの省略、整形前後の Markdown 出力の一致を確認する。 |
| 回帰 | `@env` と `@global` を含まない入力で、`check` の結果と診断、`fmt` と `generate` の出力が従来と一致することを確認する。 |
